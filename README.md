# Market Lab — учебная лаборатория анализа рынка

Проект предназначен для изучения рыночных данных и тестирования идей на истории.
Он **не подключается к биржам, не принимает торговые API-ключи и не отправляет реальные ордера**.

## Возможности
- импорт локальных OHLCV-данных из CSV;
- расчёт EMA и RSI;
- исторический backtest через готовую библиотеку `backtesting.py`;
- виртуальная симуляция на демонстрационных данных;
- сохранение отчётов и списка симулированных сделок в `reports/`;
- отдельный простой Paper Trading пример.

## Требования
- Windows 10/11
- Python 3.11+

## Установка

Открой `cmd` в папке проекта и выполни:

```bat
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Запуск исторического теста

```bat
python -m src.backtest
```

С интерактивным HTML-графиком:

```bat
python -m src.backtest --plot
```

По умолчанию используются демонстрационные данные `data/sample_market.csv`.
Результаты появятся в папке `reports/`.

Можно передать свой CSV:

```bat
python -m src.backtest --data data/my_market.csv --plot
```

CSV должен содержать столбцы:

`timestamp,open,high,low,close,volume`

Время — ISO-8601, например `2026-01-01T00:00:00Z`.

## Запуск простого Paper Trading примера

```bat
python -m src.main
```

## Настройки

Измени `config.json`:
- `starting_balance` — виртуальный стартовый баланс;
- `position_fraction` — доля виртуального баланса для учебной позиции;
- `fee_rate` — условная комиссия;
- `fast_ema`, `slow_ema`, `rsi_period`, `rsi_low`, `rsi_high` — параметры индикаторов и учебных правил.

## Структура

- `src/backtest.py` — интеграция `backtesting.py` для исторического тестирования;
- `src/indicators.py` — EMA и RSI;
- `src/strategy.py` — прозрачные учебные правила;
- `src/paper_trader.py` — симулятор виртуальных сделок;
- `src/main.py` — запуск исходного Paper Trading примера;
- `data/sample_market.csv` — синтетические демонстрационные свечи;
- `reports/` — создаваемые отчёты.

## Зависимость и лицензия

`backtesting.py` — сторонняя библиотека с лицензией AGPL-3.0. Мы подключаем её как зависимость через PyPI и не копируем её исходный код в этот проект. Перед публикацией, сетевым предоставлением или распространением проекта нужно отдельно проверить требования лицензии.

## Ограничения

Результат backtest зависит от качества данных, выбранного периода, комиссий и допущений симулятора. Он не является прогнозом или гарантией будущей доходности. Не используй демонстрационные результаты как основание для финансовых решений.
